# Last-Mile Logistics Data Analysis (Starter Project)

## Purpose

A beginner-friendly demonstration of how delivery records can be checked
and summarised to understand last-mile logistics performance.

## Files

-   `delivery_data.csv` --- a small **synthetic example dataset**, not
    real company data.
-   `analysis.py` --- Python script for basic data-quality checks,
    on-time delivery rate, and route summaries.
-   `requirements.txt` --- required Python package.

## Run

1.  Install Python 3 and open a terminal in this folder.
2.  Install dependencies: `pip install -r requirements.txt`
3.  Run: `python analysis.py`

## Important limitations

The data is fictional and only demonstrates the workflow. Do not present
its output as a real operational finding. For an actual project, use an
approved, anonymised dataset, document the source, validate definitions,
and check the results with an operations stakeholder.

## KPIs demonstrated

-   On-time delivery rate among completed deliveries.
-   Number of completed deliveries per route.
-   Average distance per route.
